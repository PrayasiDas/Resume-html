    • Air Canvas

      Air Canvas is a Python-based computer vision project that allows users to draw and create digital artwork in the air using hand gestures. Developed using Python and OpenCV, the project uses real-time hand tracking to detect finger movements and translate them into digital strokes on a virtual canvas. Key Features: - Real-time hand gesture tracking. - Virtual drawing without physical contact. - Interactive digital canvas. - Computer vision-based gesture recognition. Technologies Used:Python, OpenCV, Computer Vision.

    • Helping Hand

Key Features: - Location-based nearby NGO discovery. - NGO search and exploration. - User registration and login. - Multilingual user interface.
